Бланки для участников

Бланки собираются автоматически из сохранённой игры: раскладка блоков в ней уже зафиксирована, поэтому напечатанное гарантированно совпадёт с тем, что реально прозвучит. Укажите только количество участников — каждый получит по бланку на каждый блок (обычно три листа за игру), треки на бланках перемешаны в случайном порядке. На выходе — готовый PDF, страницы идут по блокам: сначала весь первый, потом второй, потом третий.

Оформление бланка (заголовок, номинация, QR)

Строка «N раунд: Собери комбинацию…» подставляется автоматически по номеру блока.

Сохранённые игры

Каждая сохранённая игра — отдельный именованный снимок текущей раскладки раундов (какие треки на каких числах, тексты и тайминги) — не зависит от того, что случится с банком треков потом. Скачанный архив открывается двойным кликом по HTML-файлу внутри, полностью без интернета.
